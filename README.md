# Traffic Accident Severity Classification

A machine learning project focused on classifying traffic accident severity using data-driven techniques.

## 📌 Project Overview

This project was developed as part of **CSE445: Machine Learning** at **North South University (NSU), Bangladesh**, under the supervision of **Dr. Sifat Momen**.

The project explores the application of machine learning techniques to traffic accident severity classification. By analyzing relevant accident-related features, the objective is to develop classification models that identify accident severity patterns and evaluate their predictive performance.

## 🎯 Objectives

- Explore and preprocess traffic accident data for machine learning.
- Apply machine learning classification techniques to predict accident severity.
- Evaluate model performance using appropriate classification metrics.
- Compare model results to understand the effectiveness of different approaches.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Environment:** Google Colab / Jupyter Notebook
- **Domain:** Machine Learning, Classification, Data Analysis

## ⚙️ Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or Google Colab
- Required Python libraries used in the notebook

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Karma-Sonam-Rabgay/Traffic-Accident-Severity-Classification.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Traffic-Accident-Severity-Classification
   ```

3. Open `code/CSE445_ML_Project.ipynb` in Jupyter Notebook or upload it to Google Colab.

4. Obtain the dataset from its original source, if required, and update the dataset path in the notebook.

5. Install any missing dependencies and execute the notebook cells in order.

## 📊 Evaluation

The classification models are evaluated using appropriate performance metrics, which may include:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

Refer to the project report in the `docs/` directory for the detailed methodology, experiments, and findings.
